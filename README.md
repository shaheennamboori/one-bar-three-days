# One Bar / Three Days

A self-contained static HTML guide for three 30-minute bodyweight strength sessions per week, using a pull-up bar and floor space.

## Open the guide

Open `index.html` in a browser. No installation, build step, account, or internet connection is needed to read the workouts. The external research links require internet access.

## What is included

- Four exercises per session, with sets, reps, rest periods, and a 30-minute schedule.
- Step-by-step technique, easier variations, and progression rules.
- Pull-up starting volume tailored to a current maximum of two strict reps.
- Source links to ACSM, NASM, ACE, UCLA Health, HPRC, Catalyst Athletics, and AAOS.
- Responsive layout and print styles, without external scripts or fonts.

The exercise schedule is a synthesis for general strength, not a published clinical protocol. The guide explains the coverage limits of the equipment and exercise count.
